# Project Decisions

- Evitamos librerías pesadas si no aportan valor claro
- UX y claridad pesan más que la perfección técnica

## Código
- Mantener componentes simples y legibles
- Evitar abstracciones prematuras
- Documentar decisiones importantes en este archivo

## Producto

- Menos opciones, mejor guiadas
